# 🎯 AI Roundtable

Научный симпозиум AI-моделей: несколько LLM дискутируют между собой до достижения консенсуса.

## Отличие от LLM Council

| LLM Council (Karpathy) | AI Roundtable |
|------------------------|---------------|
| Chairman решает финально | Модели сами приходят к выводу |
| 3 фиксированных этапа | Итеративная дискуссия |
| Модели оценивают | Модели спорят и меняют позиции |

## Быстрый старт

### 1. Получи API ключ

Зарегистрируйся на [OpenRouter](https://openrouter.ai) и получи API ключ.

### 2. Установка

```bash
# Клонируй или скопируй проект
cd roundtable

# Установи зависимости
npm install

# Создай .env файл
cp .env.example .env
```

### 3. Настрой API ключ

Отредактируй `.env`:

```
OPENROUTER_API_KEY=sk-or-v1-твой-ключ-здесь
```

### 4. Запусти

```bash
npm run dev
```

Открой http://localhost:3000

## Как это работает

```
Раунд 1: Все модели отвечают независимо
    ↓
Раунд 2+: Каждая модель видит ответы других
          "Что думаешь о позиции коллеги X?"
    ↓
Проверка консенсуса (LLM-as-Judge)
    ↓
✅ Консенсус → финальный ответ
⚔️ Нет консенсуса → показать лагеря
```

## Доступные модели

- GPT-4o (OpenAI)
- Claude 3.5 Sonnet (Anthropic)
- Gemini 2.0 Flash (Google)
- DeepSeek Chat
- Llama 3.3 70B (Meta)

Можно добавить другие через `lib/openrouter.ts`.
